# 🔐 Password Generator in Java  

A simple yet powerful **Password Generator** built using **Java**! 💻  
This project creates strong, random passwords with customizable lengths and character combinations, helping users improve security and protect sensitive information.

---

## 🚀 Features
- Generates **secure random passwords** instantly 🧩  
- Customizable **password length** and character types (uppercase, lowercase, numbers, symbols) 🔢  
- Uses Java’s `Random` and `SecureRandom` classes for better randomness 🎲  
- User-friendly **console interface**  
- Lightweight and easy to integrate into other applications ⚡  

---

## 🧠 Concepts Used
- String manipulation  
- Random number generation (`java.security.SecureRandom`)  
- Conditional statements and loops  
- User input handling (`Scanner`)  
- Modular programming with functions/methods
